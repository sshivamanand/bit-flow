send something

  1. Run bitflow on both computers. Each shows a pairing code at the top right.
  2. Under nearby, click files, folder or game next to the other computer.
  3. Type the code shown on their screen. They get an accept prompt and pick the folder.

Not listed? Type its address under "or", or check you're on the same network and the firewall allows bit-flow.

interrupted?

Wi-Fi drops reconnect automatically. If it stops, send the same thing again: only the missing bytes move, and identical files are skipped.

when a file already exists

refusestop the transfer (default)
keep bothsave theirs as "name (1)"
skipkeep yours, skip theirs
updateskip identical, replace changed (good for game updates)
replaceoverwrite yours

Change it in settings. Identical files are always skipped.

going faster

  • Two laptops on the same Wi-Fi router share the air twice. Plug one into the router to roughly double the speed.
  • A cable between the laptops (Ethernet, Thunderbolt) beats Wi-Fi by a lot. If both are connected, bit-flow uses both.
  • Compression is automatic: it halves the bytes for most game and app data, and skips videos and zips.

steam games

Click game, pick one, enter their code. It installs into their Steam library: restart Steam afterwards. If they have an older version, only changed files are sent.
